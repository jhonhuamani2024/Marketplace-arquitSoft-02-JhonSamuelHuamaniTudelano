# Actores del sistema

## Marketplace de productos para mascotas

Los actores son las personas, organizaciones o sistemas externos que interactúan con el Marketplace de productos para mascotas.

| Actor                   | ¿Qué necesita realizar?                                                                                                                      |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Cliente                 | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos.           |
| Seller                  | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| Administrador           | Administrar la plataforma.                                                                                                                   |
| Pasarela de pago        | Procesar pagos.                                                                                                                              |
| Servicio de envío       | Gestionar información de entrega.                                                                                                            |
| Servicio de facturación | Generar comprobantes de pago.                                                                                                                |
| ERP                     | Proporcionar información de productos y stock.                                                                                               |

## Descripción de los actores

### Cliente

Es el usuario que utiliza el marketplace para buscar productos para mascotas, consultar información, agregar productos al carrito, realizar pedidos, efectuar pagos y consultar el estado de sus pedidos.

### Seller

Es el vendedor que utiliza la plataforma para ofrecer y gestionar sus productos, actualizar su información y consultar información relacionada con sus ventas.

### Administrador

Es el responsable de administrar la plataforma y gestionar los elementos correspondientes del marketplace.

### Pasarela de pago

Es un sistema externo encargado de procesar las operaciones de pago realizadas por los clientes.

### Servicio de envío

Es un sistema externo encargado de gestionar la información relacionada con la entrega de los pedidos.

### Servicio de facturación

Es un sistema externo encargado de generar los comprobantes de pago.

### ERP

Es un sistema externo que proporciona información relacionada con los productos y el stock.
